The animation on my home page is a real run of {{ trace.model.name | split: '/' | last }}, a small open-weight model, on my name. Every token, vector, attention weight, and probability in it comes from that run. I only picked the timing.

1. Tokens

The model reads tokens, not letters. “hunter” is one token. “scheppat” is three.

It also reads an instruction I wrote, inside a chat template:

All tokens it reads

2. Vectors

Each token ID picks a row of learned numbers. These are the striped columns in the animation. Maroon is above zero, blue below.

3. Layers

The columns pass through layers. In each one, attention lets a token pull from the tokens before it. The arcs in the animation are these weights. Here they are for every token, averaged over heads:

The first column is attention to the instruction and template. Shading uses a square-root scale. Hover a square for its value.

4. Next token

After the last layer, the model scores every token it knows and takes the top one. Then it appends that token and runs again. That’s the loop in the animation.
